# 변경 이력

## 1.0.0 — 2026-09-20

SMART-SIC 관찰을 익명화한 최초 선언형 패키지. 메뉴·구성·디자인·상호작용·검증 가이드와 4개 패턴을 제공한다. 실제 운영 데이터·계정·기관 로고·소스 코드·캡처 이미지는 포함하지 않는다. 관찰 사이트의 자산 사용권을 부여하지 않는다. 지도와 열린 업무 화면 탭은 선택적 참고이며 구현 완료를 의미하지 않는다. 기계 실행 검증 규칙은 아직 없고 checks/rules.json은 빈 규칙 배열이다.

초기 호환성 검증에서 필수 기능을 실제 런타임의 grouped-layout/filter-table/record-navigation/design-tokens로 한정했다. 객체 탭과 관리 전용 탐색 구성은 optional 및 PROPOSED 가이드로 분리하고 기존 상세 정보/설정 폼을 유지한다.
