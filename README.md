# bidSkill

DocuCBD에서 선택하는 화면 구성·디자인 스킬셋 저장소입니다.

## 첫 패키지

- 패키지: `public-control-room@1.0.0`
- 태그: `public-control-room-v1.0.0`
- 패키지 경로: `packages/public-control-room`
- 메뉴·화면 구성·디자인·상호작용·검증 가이드 5종
- 관제·목록/상세·객체 상세·설정 패턴 4종

선택한 버전을 프로젝트에 고정하며, 새 버전이 올라와도 기존 화면은 자동 변경하지 않습니다. 가이드는 대화형 제안의 입력입니다. 선택만으로 사이트가 완성되거나 서버 기능이 구현되지 않습니다.

## 배포 규칙

1. 패키지 변경 시 manifest 버전을 올립니다.
2. DocuCBD 계약 검증 및 파일 해시 검증을 수행합니다.
3. 검토한 커밋에 새 태그를 추가합니다. 배포한 태그는 이동하지 않습니다.
4. 라이브러리에서 태그와 패키지 경로로 동기화합니다.

계정·인증정보·RFP 원문·운영 데이터·원본 캡처·기관 로고는 보관하지 않습니다. 관찰 사실과 제안·미확인은 references에서 구분합니다. 참조 사이트의 소스 코드나 자산 사용권을 제공하지 않습니다. 패키지 이용 범위는 manifest의 LicenseRef-Organization-Internal을 따릅니다.

현재 DocuCBD Git 가져오기는 운영자 미러 연결을 사용합니다. 자동 사이트 분석·원격 게시 API는 별도 구현 상태를 확인해야 합니다.
